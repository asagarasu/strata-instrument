# Ruling — embeddings in consolidation (dated appendix, 2026-07-10)
*Protocol FROZEN 2026-07-09; changes = dated appendices only. This records
the PI's ruling, given 07-10 evening in conversation.*

**Ruling (An):** embedding-based similarity is admissible in schema
consolidation as a *mechanical proposer*. Her words, near-verbatim:
"Embedding is not LLM if I am still understanding NLP. Humans with open
vocab will do 'person', 'people_description' or something else roughly
pointing at the same thing, and the convergence algo cannot recognize
them."

**Interpretation bound to the standing laws:**
- Embeddings PROPOSE merge candidates (ranked); the map session's human
  rulings DISPOSE. No auto-merge — unchanged from map_candidates.py law.
- "LLMs out of consolidation" continues to mean: no generative/instructed
  model judgment enters the schema. A fixed embedding function used as a
  similarity metric is classed with string normalization, not with LLM
  judgment.
- **Provenance logging required** (chair's addendum, methodological
  hygiene): the map docket marks each candidate as string-proposed vs
  embedding-proposed, so the paper can report how much of the schema
  depended on which proposer class, and reviewers can audit the
  embedding model's fingerprint on the taxonomy.
- Schema still compiles from HUMAN marks only; machine-arm marks remain
  comparison data (per the sealed-parallel discovery ruling).
