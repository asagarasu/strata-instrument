## Public-domain determinations

1. **Shakespeare 1609 Quarto text** — author d. 1616, published 1609.
   PD worldwide under any rule (life+N or publication+N; 400+ years).
   The Wikisource transcription used is of the ORIGINAL 1609 QUARTO
   ("John Wright" title-page variant), i.e. original orthography
   ("Summers day," "eye of heauen," "yeeare," "Bare rn'wd quiers") —
   NOT a modernized-spelling edition. Modernized alternatives (Rolfe
   1883, Yale/Reed 1923) exist on Wikisource but were deliberately not
   used. One markup artifact corrected and documented in each header:
   Wikisource renders the opening letter as a separate drop-cap
   element; rejoined ("S|hall" → "Shall", "T|hat" → "That").
2. **坪内逍遥 (d. 1935-02-28)** — JAPAN: life+50 expired 1986-01-01
   (2018 life+70 extension not retroactive) → PD. US: translation
   first published 1928 (早稲田大学出版部『詩篇 其二』, per NDL catalog
   records cited in the file headers) → pre-1929 → PD in US. Belt and
   suspenders: even if the scanned copy is the 1934 中央公論社 revised
   reissue, no URAA restoration (already PD in Japan on 1996-01-01) →
   PD in US regardless. **Edition caveat, stated honestly:** the scan
   set contains no colophon; whether the scanned printing is 1928 or
   1934 could not be determined from the scans (details in the file
   headers).
3. All four remaining translators are in copyright — see next section.

## Key finding: Tsubouchi DID translate the Sonnets

The task brief flagged this as uncertain (his fame is the plays). It
is now confirmed by primary evidence: the complete ソネット集 (all 154)
occupies his 『詩篇 其二』 (1928, the closing volume of his complete-
works project), and full page scans of Sonnets 18 and 73 were fetched
and manually transcribed (see `jp_target/`). Corroborating secondary
evidence: Aozora Bunko lists ソネット集 as 坪内逍遥/シェークスピア work
ID 58840 (詩篇其二 02) — still 入力中 (unreleased) as of fetch date, so
Aozora provided no text; NDL catalog records both the 1928 and 1934
editions of 詩篇其二.

## Gaps / caveats for the record

1. **Tsubouchi scan edition ambiguity** — the 1-em.net scan set lacks
   a colophon; 1928 (早稲田大学出版部) vs. 1934 (中央公論社 新修 39巻)
   printing undetermined. PD either way (reasoning above), but anyone
   citing the *printing* should verify against a library copy. NDL
   Digital Collections likely holds 詩篇其二 (lead: dl.ndl.go.jp pid
   887445) but the viewer is JavaScript-only and could not be read in
   this session — flagged as a verification lead, not used as a source.
2. **Tsubouchi transcription risk** — the .txt files are manual
   transcriptions from ~150 dpi photographs (no Aozora/NDL text exists
   to diff against). Furigana omitted; one reading flagged for
   re-check in the Sonnet 18 header (line 6 「衰へしめをはるなり」).
   Raw scans are kept alongside precisely so a human can re-verify.
3. **梁实秋 Sonnet 73 quote page: NOT FOUND.** Quote pages for his
   Sonnet 18 were found, but no scholarly/educational page quoting his
   Sonnet 73 rendering turned up. Not substituted; excerpt from the
   遠東圖書公司 print edition.
4. **梁实秋 Far East edition ISBN: NOT FOUND** (first edition predates
   ISBNs; the publisher's current catalog was unreachable this
   session).
5. **高松雄一 quote pages: NOT FOUND** for either target sonnet.
6. The zh quote-page pointers include comparison posts (Douban/blog)
   whose translator attributions were not independently verified
   against print — stated in `zh_target/locate_only_records.md`; a
   human excerpting from them must check against the cited print
   editions. The Douban posting of Tu the PI's complete translation is an
   unlicensed reproduction — recorded as a locate pointer only,
   nothing copied into this corpus.
7. 屠岸's exact 2008 revised edition was 重庆出版社 (with Penguin), not
   人民文学出版社 as the task brief's example suggested;人民文学-line
   editions exist later (e-book 全编). Both noted in the record file —
   no ISBN found for the 2008 重庆 printing.
